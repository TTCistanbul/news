EDM → HubSpot 轉換工具

把 EDM builder 匯出的 HTML，轉成可以貼進 HubSpot 文字區塊「原始碼」的版本

1選 EDM builder 匯出的 HTML 檔

點這裡選擇 EDM.html，或拖曳進來
在 EDM builder 按「⬇ Export HTML（單檔）」得到的檔案

2上傳圖片到 HubSpot，把網址貼回來

  1. 按每張圖旁邊的「下載」，存到電腦。
  2. 到 HubSpot：Content（內容）→ Files（檔案），按「Upload」上傳這些圖片。
  3. 在 HubSpot 檔案列表點圖片 → 「Copy URL（複製網址）」，貼到下面對應的格子。

Email 裡的圖片一定要放在網路上用網址連結；直接嵌在檔案裡的圖，Gmail 和 Outlook 大多不會顯示。

3檢查按鈕和連結的網址

EDM builder 的按鈕常常沒有連結。空白的請填上報名表或網頁網址，不然收件人點了沒反應。

4複製結果，貼進 HubSpot

  1. HubSpot 新增 email → 拖一個 Text（文字） 區塊到「Drop content here」。
  2. 點進文字區塊 → 工具列「⋯ 更多 / Advanced」→ Source code（原始碼）。
  3. 把裡面原本的內容刪掉，貼上複製的 HTML，按儲存。
  4. 用「Preview & test → Send test email」寄給自己，用 Gmail 和 Outlook 各看一次。
